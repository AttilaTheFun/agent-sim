# Code of conduct

agent-sim is built in the open by people with different backgrounds and levels of experience. Everyone taking part
(in issues, pull requests, discussions and anywhere else the project is represented) is expected to:

- be respectful and patient, and assume good intent;
- criticize code and ideas, never people;
- keep discussions on topic and welcoming to newcomers;
- respect others' privacy: no sharing of personal information without consent.

Harassment, personal attacks, discriminatory language and sexualized content are not tolerated. Maintainers may
edit or remove contributions and block participants who do not follow these expectations.

To report a problem, contact the maintainers privately through a GitHub security advisory on this repository or by
email to the address on the maintainer's GitHub profile. Reports are handled confidentially.
