# Security

Please report vulnerabilities privately through GitHub's
[security advisories](https://github.com/Developing-Gamer/agent-sim/security/advisories/new) rather than in a public
issue. We aim to reply within a week.

agent-sim runs Apple's simulator runtime through x86Sim, whose simulator processes are not sandboxed. Run phones on
machines you control, and never expose a phone's viewer or API without its access token.
